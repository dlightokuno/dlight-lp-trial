## 作業2：「整えてから」を「整えながら」へ

LPを作る過程で、**「整えながら鍛える」のほうが実態に近い**という結論になりました。

出現状況：「鍛える前に」9ページ／「整えてから」3ページ／「整えながら」0ページ。

### ★ここが今回いちばん注意が要ります

`index.html` の **STAGES セクションは「順番」の思想で書かれています。**

> 整えて土台をつくり、その上で鍛える。**順番を守るからこそ**、身体は安全に、確実に変わっていきます。
> Step 01 Re-Conditioning（マイナスをゼロへ）→ Step 02 Performance（ゼロをプラスへ）

**ここを「整えながら」に置き換えるとセクションの論理が壊れます。** 置換で済む話ではありません。

### 解決策：時間の尺度を分ける

2つは矛盾しません。見ている時間の長さが違うだけです。

- **数カ月の話** ＝ STAGES はそのまま残す（整える段階 → 鍛える段階へ進む）
- **1回80分の中の話** ＝「整えながら鍛える」（毎回どちらもやり、比率だけ変える）

STAGES のリード文を、この区別が伝わる文に差し替えてください。原稿：

> **数カ月かけて進む道すじと、1回80分の中身は別ものです。**
>
> 長い目で見れば、整えて土台をつくる段階から、鍛えて伸ばす段階へ進んでいきます。
> ただし**1回のセッションの中では、整えることと鍛えることを毎回どちらも行います。**その日の身体の状態で、比率だけを変えていきます。

ブログ記事内の「鍛える前に、整える」は、記事の文脈で意味が通っているなら無理に変えなくて構いません。**トップ・プログラム・料金など主要ページを優先**してください。

## 作業3：時間の構成 ← 施主がいちばん入れたい部分

**本家のFLOWには時間が一切書かれていません。**「80分」とだけあって、中で何にどれだけ使うのか分かりません。3つ入れてください。

### 3-1. その日の配分（50分・80分の3パターン）

LP の `#hybrid` セクションにあるものをそのまま移植。マークアップもCSS（`.mixes` / `.mix__bar`）もLPにあります。

見出し「その日の身体に、その日の最適な時間を。」
リード「毎回、姿勢・可動域・疲労状態を確認します。決まったメニューを繰り返すのではなく、身体の状態に合わせて、ストレッチ・自重トレーニング・ウェイトトレーニングの比率を調整します。」

| セッション時間 | 例 | 配分 |
|---|---|---|
| **50分の場合** | 身体が硬く、動きが出にくい日 | ストレッチ10分／自重15分／ウェイト25分 |
| **80分の場合** | しっかり鍛えて、最後に緩める日 | ウェイトトレーニング40分／ストレッチ40分 |
| **80分の場合** | 疲労が抜けきっていない日 | 全身ケアストレッチ40分／自重20分／ウェイト20分 |

**50分の例と80分の例を混ぜているので、各カードに時間のバッジ（「50分の場合」）を必ず付けること。**
無いと、帯の長さの差が「その日の内容の違い」に見えてしまいます。

**帯の幅は時間に厳密に比例させること。** `--w` に「80分に対する割合」を入れ、幅は `calc(var(--w)*2)`
（＝40分が幅100%）。**文字は帯の中に入れないこと。** LPでは帯の中に置いていたら
`min-width:max-content` が効いて10分の帯が15分より長くなっていました。文字は上、帯は下に分けてください。

注記「帯の長さは時間の目安です。実際の配分は当日の状態で決まります。50分・80分のほか110分もお選びいただけます。」

置き場所：`program.html`。`index.html` にも要約版を置くと効果的。

### 3-2. 体験80分の内訳（FLOWに時間を足す）

本家のFLOWは STEP 1〜6 で内容だけ。**各ステップに時間を足すだけ**で解像度が上がります。LPでは5ステップに整理しました。

1. カウンセリング・各種チェック **30分**
2. パーソナルストレッチ **10分**
3. 自重トレーニング **15分**
4. ウェイトトレーニング **15分**
5. 今後の進め方のご提案 **10分**

### 3-3. 50分・110分の位置づけ ← 本家だけの価値

LPは80分だけを扱いましたが、**本家は50分・80分・110分の3つ**があります。

いま本家は「80分がおすすめ」と言っているのに、**その理由が書かれていません。** ここを説明すると初めて根拠が付きます。

- **50分** ＝ 目的を絞る時間。ストレッチかトレーニングのどちらかに寄せる

- **110分** ＝ 両方に加えて、動きの確認や種目を増やせる時間

**実際の配分は施主にしか出せない数字です。** 確認してから数字を入れてください。分からないうちは、上の考え方だけを載せて数字は空けておくこと。

## 実装で踏みやすい不具合（LPで実際に起きたもの）

| 症状 | 原因と対処 |
|---|---|
| 自前の番号の左に「1. 2. 3.」が二重で出る | `list-style:none` を `ul` にしか当てていない。`ul,ol` にする |
| 金額が桁の途中で改行される | 日本語の折り返し（`auto-phrase`）は**数字が対象外**。`.nw` か `white-space:nowrap` で囲う |
| 中央寄せの見出しの行がばらつく | 短い見出し・リードは `text-wrap:balance`。**本文は `pretty` のまま** |
| 写真の被写体が特定の画面幅だけ切れる | 高さを `svh` や固定pxにしている。`aspect-ratio` で幅から決める |
| 固定ヘッダーの裏にコンテンツが潜る | ヘッダーの高さは中身の折り返しで変わる。JSで実測して CSS 変数に渡す |
| 表を入れたらページ全体が横スクロールになる | 表を `overflow-x:auto` の箱に入れていない |
