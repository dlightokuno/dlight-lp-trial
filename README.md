本家サイト（`../ホームページ作成/site/`）の内容とデザインをもとに作成していますが、
**CSS・JS・画像まで含めてこのフォルダだけで完結する自己完結型**です。本家を編集しても、このLPには影響しません（逆も同じ）。

## プレビュー

```bash

```

## 編集時のルール

- **グローバルナビは意図的に置いていません。** LPは離脱を防ぐため、ヘッダーはロゴ＋予約ボタンのみ。
  ナビを足したくなったら、それは本家サイト側の役割です。
- **色・フォント・余白は `lp.css` の `:root` を触る。** 個別要素にハードコードしない。
- 既存クラス（`.section` / `.sec-head` / `.grid` / `.card` / `.split` / `.stage` / `.prog` / `.flow` /
  `.trial-card` / `.ptable` / `.acc` / `.cta-band` / `.notes` / `.trouble` / `.reason` / `.num-card`）で
  組めないか確認してから新しいクラスを足す。
- スクロール表示アニメーションは `data-reveal` 属性を付けるだけで効く。
- 日本語の見出しは明朝（`--f-serif`）、本文はゴシック（`--f-sans`）、英字は Jost（`--f-en`）。
- 画像を追加するときは軽量化してから置く（長辺1200px / JPEG品質72 目安、ヒーローのみ1600px）。
  `sips -s format jpeg -s formatOptions 72 -Z 1200 in.jpg --out out.jpg`

## 掲載内容の出どころ

料金・経歴・資格・FAQ はすべて本家サイト（＝Wix版の実データ）から転記しています。
**勝手に数字や実績を作らないこと。** 不明な値は「公式LINEでお問い合わせください」に寄せます。

- 体験トレーニング 80分 5,000円（税込）／入会金 通常 33,000円（税込）
- 掲載している月額プランは**50分コース**（月2回 19,800円／月4回 37,400円／月8回 70,400円）。80分コースは注記で触れるのみ。
- 「1,000名以上」「セッション1万件以上」「ストレッチ継続率9割超え」は代表・奥野個人の実績としてABOUTページに記載のあるもの。ジム全体の実績として書き換えないこと。
- **お客様の声（40代男性）は施主から提供された実際の声**です。本家サイトには未掲載。文面を勝手に脚色しないこと。
- 会員データの円グラフ（年代・入会時の経験・目的）は本家トップと同じ構成比で、**元画像から再現した概算**です。そのため「※構成比は概算です」の注記を必ず残すこと。正確な数値が手に入ったら差し替えます。

## 公開について（未実施）

- `canonical` / `og:url` は `https://www.dlightgym.com/lp/trial/` を仮で入れてあります。
  実際の公開URLが決まったら、`index.html` の以下3か所を実URLに直してください。
  `<link rel="canonical">` / `<meta property="og:url">` / JSON-LD（Service）の `offers.url`
- `og:image` は本家サイトの画像URLを参照しています（`https://www.dlightgym.com/assets/img/hero-home.jpg`）。
  本家と別ドメインで公開する場合は、このLPの `assets/img/hero-home.jpg` の絶対URLに差し替えてください。
- 広告の流入計測をする場合は、`assets/js/analytics.js` 冒頭の `GA_MEASUREMENT_ID` に測定IDを入れるだけで
  予約クリック（`reserve_click` / `generate_lead`）、LINEクリック、FAQ開封、読了率が記録されます。
  空のままなら外部への送信は一切ありません。
