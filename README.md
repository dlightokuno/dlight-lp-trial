# D/LIGHT GYM 体験トレーニング LP

八丁堀・新富町のパーソナルジム「D/LIGHT GYM」の**体験トレーニング申込に特化した1枚完結のランディングページ**。
広告・SNS・チラシQRなどからの流入先を想定しています。

本家サイト（`../ホームページ作成/site/`）の内容とデザインをもとに作成していますが、
**CSS・JS・画像まで含めてこのフォルダだけで完結する自己完結型**です。本家を編集しても、このLPには影響しません（逆も同じ）。

## プレビュー

```bash
python3 serve.py
```

→ http://localhost:4322 （停止は Control + C）

### 2026年8月の全面改稿でやったこと

本家HPの更新（ビフォーアフター新設・料金の可視化）と、マーケティング／UI観点のレビューを反映した。

- **ビフォーアフター4件を新設**。証拠を「体験の案内」より前に置き、共感→証拠→理由の順にした
- **料金の透明化** — 都度払いは「入会金なし」と明示、初月総額を計算して提示。「あとから費用が出てくる」不信を消すため
- **指名料の表は施主の指示により非掲載**（2026年8月）。金額を並べると体験前の心理的ハードルになるため、代わりに「総額は体験時にその場でお出しします」に寄せている。
  そのため料金セクションとFAQでは**「追加費用はない」と言い切らず「基本的に」を必ず残すこと**（指名料自体は実在するため）
- **料金セクションの末尾に予約CTAを設置**。以前は本家サイトへの外部リンクしか出口がなく、`analytics.js` の `price_block` イベントが構造上ゼロだった
- お客様の声を1件→3件（ゴルフの声を追加。八丁堀の40代男性はゴルフ層と重なる）
- FAQに支払い方法・縛り・追加費用・仕事帰りの4問を追加（すべて本家の実データ）
- ヒーローのh1を最終的に**「運動は10年ぶり。それでも、体は変えられる。」**に変更。
  マッサージ前提のコピーだと通院習慣のない層を外すため、「自分にはもう無理だ」という障壁のほうを狙った。
  年齢を書かずに「10年ぶり」で30〜50代を想起させ、上の年代も弾かない
- **ファーストビューの証拠写真とビフォーアフターの主役を、どちらも50代男性の姿勢改善で統一**。訴求の軸をぶらさないため
- **オーダーメイド帯（`.made`）と「こんな方におすすめです」（`#recommend`）を新設**。
  プログラム3種を見せたあとの「で、自分はどれ？」を受け止め、体験セクションへ渡す導線にした。
  `#recommend` の末尾は施主の文言で「リバウンドをしない適切な痩せ方を提案する／急激なダイエットは推奨しない」と明示している
- 朝8時から営業していることをヒーローとFAQで訴求（仕事前に通える差別化）
- スマホでヒーローの予約ボタンがファーストビューに入るよう、`order` で価格の直後に配置
- 全画像をWebP化（3.0MB→1.8MB）。OGP用に `hero-home.jpg` のみJPGを残置
- JS未実行でも本文が消えないよう `<noscript>` でフォールバックを追加
- スマホ固定CTAの出現位置を固定420pxからヒーロー高さ基準に変更

## 広告を回すときの準備（未実施）

### 1. まず計測ID（これが無いと何も検証できない）

`assets/js/analytics.js` 冒頭の `GA_MEASUREMENT_ID` が**空のまま＝完全に無計測**。広告に1円使う前に測定IDを入れること。

### 2. UTM の付け方

LP側は、着地URLの `utm_*` / `gclid` / `fbclid` を **Square の予約URLに自動で引き継ぐ**（`assets/js/lp.js` の末尾）。
あわせて `lp_cta`（hero / results / trial / price / cta_band / mobile_bar など）も付くので、
「どの広告の、どのボタンから予約されたか」まで追える。

広告のリンク先URLの例：

```
https://dlightgym.com/lp/trial/?utm_source=google&utm_medium=cpc&utm_campaign=trial_2608_pain&utm_content=headline_a
```

命名は次で統一する。

- `utm_source`：`google` / `facebook` / `instagram` / `flyer` / `line`
- `utm_medium`：`cpc`（広告）/ `qr`（チラシ）/ `profile`（SNSプロフィール）
- `utm_campaign`：`trial_年月_訴求`（例 `trial_2608_pain`、`trial_2608_golf`）
- `utm_content`：クリエイティブの識別名

**要確認：** Square が未知のクエリパラメータを受け取っても予約ページが正常に開くか、実機で1回試すこと。
開かない場合は `lp.js` 末尾のブロックを削除すれば元に戻る。

### 3. 検索広告のキーワード案（下書き・要精査）

## 編集時のルール

- **グローバルナビは意図的に置いていません。** LPは離脱を防ぐため、ヘッダーはロゴ＋予約ボタンのみ。
  ナビを足したくなったら、それは本家サイト側の役割です。
- **色・フォント・余白は `lp.css` の `:root` を触る。** 個別要素にハードコードしない。
- 既存クラス（`.section` / `.sec-head` / `.grid` / `.card` / `.split` / `.stage` / `.prog` / `.flow` /
  `.trial-card` / `.ptable` / `.acc` / `.cta-band` / `.notes` / `.trouble` / `.reason` / `.num-card` /
  `.made` / `.rec` / `.assure` / `.sim` / `.campaign` / `.proof`）で
  組めないか確認してから新しいクラスを足す。
- スクロール表示アニメーションは `data-reveal` 属性を付けるだけで効く。
- 日本語の見出しは明朝（`--f-serif`）、本文はゴシック（`--f-sans`）、英字は Jost（`--f-en`）。
- 画像を追加するときは軽量化してから置く（長辺1200px / JPEG品質72 目安、ヒーローのみ1600px）。
  `sips -s format jpeg -s formatOptions 72 -Z 1200 in.jpg --out out.jpg`

## 掲載内容の出どころ

料金・経歴・資格・FAQ はすべて本家サイト（＝Wix版の実データ）から転記しています。
**勝手に数字や実績を作らないこと。** 不明な値は「公式LINEでお問い合わせください」に寄せます。

- 体験トレーニング 80分 5,000円（税込）／入会金 通常 33,000円（税込）
- 初月のお支払い例は **入会金半額（16,500円）を適用した金額**で計算している。キャンペーンを終了するときは、この2枚のカード（53,900円／72,600円）も 70,400円／89,100円 に戻すこと。
- **ビフォーアフターの写真は本人の許諾済み。**「効果には個人差があり、結果を保証するものではありません」の注記を必ず残すこと（`.ba__note`）。
- ヘッドコンディショニングのビフォーアフター（20代男性・頭のサイズ）は、別サービスで予約URLも違うため**このLPには載せていない**。
- 「1,000名以上」「セッション1万件以上」「ストレッチ継続率9割超え」は代表・奥野個人の実績としてABOUTページに記載のあるもの。ジム全体の実績として書き換えないこと。
- **お客様の声（40代男性）は施主から提供された実際の声**です。本家サイトには未掲載。文面を勝手に脚色しないこと。
- 会員データの円グラフ（年代・入会時の経験・目的）は本家トップと同じ構成比で、**元画像から再現した概算**です。そのため「※構成比は概算です」の注記を必ず残すこと。正確な数値が手に入ったら差し替えます。
