# D/LIGHT GYM 体験トレーニング LP

八丁堀・新富町のパーソナルジム「D/LIGHT GYM」の**体験トレーニング申込に特化した1枚完結のランディングページ**。
広告・SNS・チラシQRなどからの流入先を想定しています。

本家サイト（`../ホームページ作成/site/`）の内容とデザインをもとに作成していますが、
**CSS・JS・画像まで含めてこのフォルダだけで完結する自己完結型**です。本家を編集しても、このLPには影響しません（逆も同じ）。


### 2. UTM の付け方

LP側は、着地URLの `utm_*` / `gclid` / `fbclid` を **Square の予約URLに自動で引き継ぐ**（`assets/js/lp.js` の末尾）。
あわせて `lp_cta`（hero / results / trial / price / cta_band / mobile_bar など）も付くので、
「どの広告の、どのボタンから予約されたか」まで追える。

広告のリンク先URLの例：

```
https://dlightgym.com/lp/trial/?utm_source=google&utm_medium=cpc&utm_campaign=trial_2608_pain&utm_content=headline_a
```

命名は次で統一する。

- `utm_source`：`google` / `facebook` / `instagram` / `flyer` / `line`
- `utm_medium`：`cpc`（広告）/ `qr`（チラシ）/ `profile`（SNSプロフィール）
- `utm_campaign`：`trial_年月_訴求`（例 `trial_2608_pain`、`trial_2608_golf`）
- `utm_content`：クリエイティブの識別名

**要確認：** Square が未知のクエリパラメータを受け取っても予約ページが正常に開くか、実機で1回試すこと。
開かない場合は `lp.js` 末尾のブロックを削除すれば元に戻る。

## ファーストビューの切り抜き写真

`hero-cutout.webp`（トレーニング）と `hero-cutout-stretch.webp`（ストレッチ）は、
写真の背景をmacOS標準のVisionで抜いたもの。色面の上端から人物の頭が飛び出す配置にしている。

新しく作るときは `tools/cutout.swift` を使う。`rembg` などのインストールは要らない。

```bash
swiftc -O tools/cutout.swift -o /tmp/cutout && /tmp/cutout 元画像.png 抜き.png
```

そのあと Python で仕上げる。**この2工程を飛ばすと輪郭に芝生の緑が残る。**

```python
from PIL import Image, ImageFilter
im = Image.open('抜き.png'); r,g,b,a = im.split()
a = a.filter(ImageFilter.MinFilter(5)).filter(ImageFilter.GaussianBlur(0.6))  # 2px内側へ削る
out = Image.merge('RGBA',(r,g,b,a)); out = out.crop(out.split()[3].getbbox())
out.save('assets/img/hero-cutout-xxx.webp','WEBP',quality=82,method=6)
```

**配置で守ること。**

- **画像の下端は胴体が切れた平らな面。** 必ず色面の下端にそろえて隠す。下や横へはみ出させない。
- **上へ飛び出す量は `--cut-out`。** 固定ヘッダー（狭い端末では65px→85pxに伸びる）に
  頭がかからないよう、`.fv` の `padding-top` を必ず一緒に確認する。
- **2枚並べるのに必要な幅は「人物の高さ × 比の合計 −（重ね量12%）」。**
  現在の比はトレーニング0.78・ストレッチ0.46で、合計約1.24。
  パネル幅から逆算して、**左右に40px前後の余白が残る高さ**にしておくこと。
  余白ゼロまで詰めると角丸の外へはみ出して見える。
  **写真を差し替えると比が変わるので、高さは毎回パネル幅から逆算し直すこと。**
- **ファーストビューはPCも1カラム**（2026年8月に2カラムから変更）。
  左右に振り分けると写真だけが右に離れて見えるため、色面のパネルを中央に置き、
  その下にコピーを中央寄せで積む形にした。`.fv__in` は `max-width:760px` で行長を抑えている。
- **トレーニング側は、ラットマシンの下側のバー（元画像 y≈1050以下）を落として使っている。**
  切り抜くと宙に浮いて見えるため。切り口はお客様の胴と腕なので色面の下端に隠れる。
- **ストレッチ側の右端はCSSでぼかしている（`mask-image`）。** 寝ているお客様の身体が
  横に長く、どこで切っても右端にまっすぐな切り口が出るため。マスクは `filter` のあとに
  かかるので、`drop-shadow` の輪郭も一緒に消える。**外すと切り口がそのまま出る。**
- **ストレッチ側はお客様の顔から下を切って使っている。** 全身を入れると1枚の中に人物が小さく
  収まってしまうため。切る位置は元画像の y=880 付近（お客様の胴体の面）。
  ここで切ると下端が一様な面になり、色面の下端にそろえたとき切り口が見えない。
- **並び順に意味がある。** スマホでは2枚合わせて帯より広くなり左右が切れるので、
  切れてよい側（トレーニング＝トレーナーの腕／ストレッチ＝お客様の足）が外を向くように、
  トレーニングを左、ストレッチを右に置いている。入れ替えると寝ているお客様の顔が画面外に出る。

## 編集時のルール

- **グローバルナビは意図的に置いていません。** LPは離脱を防ぐため、ヘッダーはロゴ＋予約ボタンのみ。
  ナビを足したくなったら、それは本家サイト側の役割です。
- **色・フォント・余白は `lp.css` の `:root` を触る。** 個別要素にハードコードしない。
- 既存クラス（`.section` / `.sec-head` / `.grid` / `.card` / `.split` / `.stage` / `.prog` / `.flow` /
  `.trial-card` / `.ptable` / `.acc` / `.cta-band` / `.notes` / `.trouble` / `.reason` / `.num-card` /

## 掲載内容の出どころ

料金・経歴・資格・FAQ はすべて本家サイト（＝Wix版の実データ）から転記しています。
**勝手に数字や実績を作らないこと。** 不明な値は「公式LINEでお問い合わせください」に寄せます。

- 体験トレーニング 80分 5,000円（税込）／入会金 通常 33,000円（税込）
- 初月のお支払い例は **入会金無料を適用した金額**で計算している。現在は入会金0円のため、初月合計＝月額（37,400円／56,100円）。
  キャンペーンを終了するときは、この2枚のカードを 70,400円／89,100円 に戻し、`sim__after` の「入会金が無料なので〜」の一文も消すこと。
- **ビフォーアフターの写真は本人の許諾済み。**「効果には個人差があり、結果を保証するものではありません」の注記を必ず残すこと（`.ba__note`）。

- **お客様の声（40代男性）は施主から提供された実際の声**です。本家サイトには未掲載。文面を勝手に脚色しないこと。
- 会員データの円グラフ（年代・入会時の経験・目的）は本家トップと同じ構成比で、**元画像から再現した概算**です。そのため「※構成比は概算です」の注記を必ず残すこと。正確な数値が手に入ったら差し替えます。
